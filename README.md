# 📒 나의 교무수첩

담임 업무용 개인 교무수첩 웹앱입니다. 파일 하나(`index.html`)로 동작하고, GitHub Pages에 무료로 올려 PC·휴대폰 어디서나 주소로 접속할 수 있어요.

## 기능
- **오늘**: 한 줄 기록, 오늘 시간표, 다가오는 7일 일정, 할 일, 오늘 출결, 급식, 메모
- **달력**: 월간 달력에 내 일정(업무·학사·개인) + NEIS 학사일정 + 할 일 마감 표시
- **학급**: 명렬표(엑셀 붙여넣기), 출결 입력(결석·지각·조퇴·결과 + 사유), 월별·연간 출결 통계, CSV 내보내기
- **기록·상담**: 학생별 누가기록·상담·칭찬·생활지도·세특 메모, 필터, 인쇄, CSV 내보내기
- **시간표**: 주간 시간표, 교시 시작 시각 편집
- **할 일**: 마감일 있는 업무 체크리스트
- **진학**: 광주 고입 내신 300점 산출(기본계획 산출지침 그대로), 학기별 성취도·비교과 일괄 붙여넣기, 반 석차
- **설정**: 학교 검색(NEIS), 여러 기기 자동 동기화(Firebase), 백업 파일 받기/불러오기, 새 학년 초기화

## GitHub Pages로 올리기 (10분)
1. https://github.com 에 가입하고 로그인합니다.
2. 오른쪽 위 **+ → New repository** → 이름 예: `gyomu` → **Public** 선택 → **Create repository**.
3. 만들어진 저장소 화면에서 **uploading an existing file** 링크를 눌러 `index.html`(과 이 README.md)을 끌어다 놓고 **Commit changes**.
4. 저장소 **Settings → Pages** → Source: **Deploy from a branch**, Branch: **main / (root)** → **Save**.
5. 1~2분 뒤 `https://내아이디.github.io/gyomu/` 주소로 접속하면 끝. 휴대폰에서는 "홈 화면에 추가"하면 앱처럼 쓸 수 있어요.

수정할 때는 저장소에서 `index.html`을 열고 연필(✏️) 아이콘으로 고친 뒤 Commit하면 1~2분 후 반영됩니다.

## ⚠️ 학생 정보는 어디에 저장되나요?
- GitHub에 올라가는 것은 **프로그램 코드뿐**이고, 학생 명단·출결·기록은 **각 기기의 브라우저 안(localStorage)**에만 저장됩니다. 저장소가 공개(Public)여도 학생 정보는 노출되지 않아요.
- 기본 상태에서는 **PC와 휴대폰의 데이터가 자동으로 합쳐지지 않아요.** 아래 "자동 동기화 설정"을 하거나, 설정 → 백업 파일 받기 → 다른 기기에서 불러오기로 옮깁니다.
- 브라우저 방문 기록/사이트 데이터를 지우면 함께 지워지니 **주 1회 백업**을 권장합니다(7일 지나면 오늘 화면에 알림이 떠요).
- 백업 파일(.json)에는 학생 개인정보가 들어 있으니 **GitHub 저장소에 절대 올리지 마세요.** 학교 PC/개인 클라우드 등 안전한 곳에 보관하세요.

## ☁️ 자동 동기화 설정 (PC·휴대폰 자동 연동, 무료, 15분)
본인 소유의 Firebase(구글 클라우드) 공간에 저장하는 방식이에요. 데이터는 선생님 계정만 읽고 쓸 수 있게 잠급니다.

1. https://console.firebase.google.com 접속 → **프로젝트 추가** → 이름(예: `my-gyomu`) → Google 애널리틱스는 꺼도 됩니다.
2. 왼쪽 **빌드 → Authentication → 시작하기 → 로그인 방법: Google → 사용 설정 → 저장**.
3. 같은 화면 **설정 → 승인된 도메인 → 도메인 추가**: `내아이디.github.io` 입력.
4. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기** → 위치 `asia-northeast3 (서울)` → **프로덕션 모드**로 시작.
5. Firestore **규칙** 탭에서 아래 내용으로 바꾸고 **게시**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /gyomu/{userId} {
         allow read, write: if request.auth != null && request.auth.uid == userId;
       }
     }
   }
   ```
6. 프로젝트 개요 옆 ⚙️ **프로젝트 설정 → 내 앱 → 웹(</>) 아이콘** → 앱 닉네임 입력 → 등록 → 화면에 나오는 `const firebaseConfig = { … };` 부분을 복사.
7. 교무수첩 **설정 → ☁️ 여러 기기 자동 동기화 → Firebase 연결 정보 붙여넣기** → 붙여넣고 저장 → **Google 계정으로 로그인**.
8. 다른 기기(휴대폰 등)에서는 같은 주소로 접속해 7번만 반복하면 됩니다. 처음 로그인할 때 "클라우드 데이터를 가져올지" 물어보면 **확인**을 누르세요.

- 화면 오른쪽 위에 `☁️ 동기화됨 17:20`처럼 상태가 보여요. 입력하면 1초 남짓 뒤 자동 저장되고, 다른 기기 화면에도 바로 반영돼요.
- 인터넷이 끊겨도 이 기기에는 계속 저장되고, 다시 연결되면 올라가요. 두 기기에서 동시에 고치면 **나중에 저장한 쪽**이 남으니, 한 번에 한 기기에서 입력하는 걸 권장해요.
- `firebaseConfig`는 비밀번호가 아니라 공개돼도 괜찮은 주소 정보예요. 보안은 5번 규칙이 지켜 줍니다.
- 학생 개인정보를 개인 클라우드에 저장하는 것이므로, 학교·교육청의 개인정보 처리 지침을 한 번 확인해 주세요. 동기화를 쓰지 않으면 지금처럼 기기 안에만 저장돼요.

## 🎓 진학 (광주 고입 내신 300점)
광주광역시 고등학교 입학전형 기본계획의 **내신성적 산출지침**(교육감 선발 후기 평준화고) 그대로 계산해요.

| 영역 | 배점 | 산출 |
|---|---|---|
| 일반교과 | 180 | 1-2 18 · 2-1 36 · 2-2 36 · 3-1 45 · 3-2 45 (10:40:50), 학기 점수 = 배점 × 환산점수 합 ÷ (과목수×5), A5 B4 C3 D2 E1 |
| 예체능 | 60 | 체육·음악·미술 3년간, 60 × (A5 B4 C3 합 ÷ 개수×5) |
| 출결 | 15 | 학년별 5점, 미인정 결석일수(지각·조퇴·결과 3회=1일): 0일 5 / 1~2일 4 / 3~4일 3 / 5~6일 2 / 7~8일 1 / 9일↑ 0 |
| 봉사 | 15 | 학년별 연간 7시간↑ 5 / 6시간 4.5 / 5시간 4 / 4시간 3.5 / 3시간↓ 3 |
| 창의적체험활동 | 15 | 학년별 4.5 + 가산 0~0.5 |
| 행동발달 | 15 | 학년별 4.5 + 가산 0~0.5 |

- 반올림: 학기 비율은 소수 여섯째 자리, 일반교과 합계·예체능은 넷째 자리에서 반올림.
- 수·우·미·양·가(예체능 우수·보통·미흡) 평어도 자동으로 A~E로 바꿔 읽어요.
- **일괄 붙여넣기**: 학기별 일반교과 성취도, 예체능, 출결, 봉사, 창체·행동 가산점을 엑셀에서 복사해 넣을 수 있어요.
- 아직 성적이 없는 학기는 입력된 학기 평균으로 추정(*)해 가내신을 보여 줘요(산출 기준에서 끌 수 있음).
- 매년 기본계획이 바뀌면 `index.html`의 `JH_SEMS`, `attPts`, `volPts` 부분만 고치면 돼요.

## 급식·학사일정 (NEIS)
설정 → 학교 이름 검색 → 선택하면 자동으로 표시됩니다. 잘 안 뜨면 https://open.neis.go.kr 에서 무료 인증키를 발급받아 설정에 넣어 주세요.
